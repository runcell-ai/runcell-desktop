# Runcell Desktop 0.3.6

Stable patch release with signed and notarized macOS installers for Apple Silicon and Intel.

Fixes the desktop reasoning-effort selector capping models such as Opus 5.5 at High even when RunCell supports Max. Per-model limits now come from RunCell's current model settings. Saved reasoning preferences survive temporary capability changes, while outgoing requests respect the current limit.

Desktop source revision: `65dc2dbb4b6626d21436ae2a611246906c8be1a4`. RunCell remains at 0.2.7, built from revision `5d180c95155714d0ad79bfee72375a910aaa6382`.

Local checks passed lint, formatting, source/test types and 379 fast regressions, with three opt-in integration tests skipped. The complete Electron suite passed. An isolated built-desktop scenario verified Opus 5.5 Max selection, capability downgrade and recovery, preserved preferences, and the outgoing reasoning parameter through actual main/preload/renderer IPC with synthetic HTTP responses. No live model requests or production accounts were used.

CI passed Linux quality checks and macOS Electron, development-client and real Jupyter integration scenarios. An existing sidebar test was made to wait for its interactive menu state before sending Escape; its original assertions remain intact. Both release targets passed native build, package audit, architecture, signature, Gatekeeper and notarization checks.

Published stable release: [v0.3.6](https://github.com/runcell-ai/runcell-desktop/releases/tag/v0.3.6), 2026-10-17T08:02:46Z.
