# Runcell Desktop 0.3.7

Stable patch release that bundles RunCell 0.2.9 in both the Python runtime and the desktop UI components.

The bundled source is the 2026-10-26 commit `release: publish RunCell 0.2.9 (#268)`, revision `922c3340d9ac19ad3139bf64638c09680d552cef`. The desktop wheel is rebuilt from that committed source with a desktop source-revision marker. Its checksum differs from the PyPI wheel.

Desktop source revision: `6f903dc07ba5122e10acd31c23468f552b6934ea`.

This release also includes desktop changes since 0.3.6: recoverable tool approvals, safer login recovery, the unified Agent sidebar with unread state, pinning and archive undo, consistent navigation icons, and RunCell history ownership and folder filtering aligned with Jupyter.

## Validation

Local Node 22.20.0 and Yarn 1.22.19 checks passed lint, formatting, source and test types, 378 fast TypeScript regressions, five release-publisher tests and 33 development-tool tests. Three opt-in tests were skipped in the fast lane.

The refreshed macOS arm64 runtime passed `yarn setup` and `yarn doctor`, reporting RunCell 0.2.9, the pinned source revision and JupyterLab 4.6.4. Both real Jupyter integration tests passed, covering independent projects, kernels, loopback servers, offline managed-environment preparation, reuse and repair.

The complete Electron suite passed, including actual main/preload/renderer startup, runtime and IPC verification, sidebar interaction, task approvals and cancellation, recursive tasks and browser lifecycle. A CI-only timing failure in the sidebar fixture was fixed by waiting for menu rendering and passive event listeners before sending the next keyboard event. The original keyboard-close and permission assertions remain intact.

`yarn package` passed its bundled-runtime verification and package audit. The packaged Python imports report RunCell 0.2.9 and the pinned source revision. The local package is unsigned; signed distributables are built by the release workflow.

[Source CI](https://github.com/ObservedObserver/runcell-desktop/actions/runs/40347838091) passed Linux quality checks, macOS Electron scenarios, development-runner isolation/restart/recovery tests, real Jupyter integrations and the final required-check gate.

No live model requests or production profiles are part of this validation. Interactive Intel execution, installer/profile migration and an end-to-end upgrade from an older installed app were not exercised. The existing dependency `eval` and large-bundle build warnings remain.
