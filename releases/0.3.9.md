# Runcell Desktop 0.3.9

Published November 17, 2026. [Download 0.3.9](https://github.com/runcell-ai/runcell-desktop/releases/tag/v0.3.9).

Runcell Desktop 0.3.9 updates bundled RunCell from 0.2.9 to 0.2.10, including the
shared chat components. It also includes the browser login fix for large cookies.

The bundled Jupyter extension now uses Agent mode throughout, offers permission
modes in its input menu, and automatically delivers official skills before tasks.
Other changes include tables in chat output, sequential image reads, generated
document links, and fixes for notebook output ordering, history and execution
recovery after refresh. The desktop's separate native composer retains its own
controls.

## Validation

Local lint, formatting, source/test types and desktop build passed. All 385
enabled TypeScript regressions passed at concurrency 2, with three opt-in tests
skipped, and all 43 publisher/development-tool checks passed. Default local
concurrency hit two subprocess startup deadlines; the focused checks passed.
These regressions are auxiliary checks, not real integration acceptance.

Real local acceptance passed both Jupyter integration tests and the complete
Electron suite. A separate built desktop run verified actual main/preload/renderer
identity, IPC and the pinned RunCell runtime using an empty isolated profile.
The runtime was RunCell 0.2.10 and JupyterLab 4.6.6. Initial runtime preparation
exceeded a verification deadline; the standard rebuild and subsequent verification
passed without relaxing the deadline.

The [PR CI](https://github.com/ObservedObserver/runcell-desktop/actions/runs/44041630983)
passed the original `check:all` command, macOS Electron/development/Jupyter checks,
Windows NSIS installation and execution, and Linux x64/arm64 AppImage and Deb
acceptance. Native checks use actual packaged IPC and offline managed environments
with real Jupyter start/stop. The CI runner was changed from retired macOS 14 to
macOS 26, which the release workflow already uses.

All checks use isolated test profiles. No live model calls, production profiles,
provider sign-in flows or upgrade from an existing installed desktop were tested.
The earlier RunCell 0.2.10 release's model acceptance is separate evidence and
is not claimed as a new desktop model test.
