# Runcell Desktop 0.3.5

Stable release published with signed and notarized macOS installers for Apple Silicon and Intel.

Runcell Desktop 0.3.5 bundles RunCell 0.2.7, with Python and UI components built from revision `5d180c95155714d0ad79bfee72375a910aaa6382`.

Desktop source revision: `79a3fa36008132d85667e6cae917b0d80f7d1d3c`.

- Adds a conversation browser and browser tools for Code Agents, with conversation isolation, human takeover and provider capability checks.
- Adds delegated and recursive Code Agent tasks with isolated workspaces.
- Reduces repeated Jupyter environment preparation and opens new RunCell conversations while history loads.
- Fixes streamed history reconciliation, browser cleanup, narrow header layouts and development client shutdown.
- Verifies the actual loaded desktop build and treats renderer console errors as acceptance failures.

Local acceptance passed lint, formatting, source/test types, 372 fast regressions, the Electron suite, two real Jupyter integration scenarios, strict development runner scenarios, standard packaging and package audit. Required CI also passed Linux quality checks and the complete macOS desktop lane, including Jupyter integration. Three opt-in tests were skipped in fast checks; the real Jupyter scenarios were run separately. No live provider or model requests were made by acceptance tests.

Independent source acceptance passed 13 actual client captures with 100 assertions. The unpacked arm64 app also passed independent first-use environment creation from the bundled wheelhouse with pip network access disabled. These runs used fresh synthetic profiles with providers disabled.

The exact public Apple Silicon DMG was downloaded and independently exercised with another fresh synthetic profile. Developer ID signature verification, Gatekeeper notarization assessment and stapled-ticket validation passed. Its size and SHA-256 matched the public manifest. First-use environment creation from offline wheels, RunCell 0.2.7 and its source stamp, actual main/preload/renderer IPC, Jupyter startup, extension ping and history IPC, public Jupyter stop, PID/port cleanup and unchanged package hashes all passed. The mounted image was detached after all owned processes exited.

Intel installers passed native Intel CI build, package audit, architecture, signature, Gatekeeper and notarization checks. Interactive Intel client execution, real accounts and model calls, the first-launch Gatekeeper dialog, normal application Quit, production profile migration and end-to-end automatic updates were not exercised. Update metadata was validated separately.

The signed-package smoke did not execute notebook cells or the complete browser workflow.
